# Portfólio Profissional - Igor Soares Karas

## Sobre o projeto

Este projeto apresenta meu portfólio profissional, desenvolvido como atividade da Agenda 15 de Desenvolvimento de Sistemas I.

O objetivo é apresentar minha trajetória, formação, habilidades e projetos na área de tecnologia e desenvolvimento.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## Estrutura do projeto

- index.html: estrutura principal do site.
- css/style.css: estilos e personalização visual.
- js/script.js: funcionalidades JavaScript.
- imagens/: arquivos de imagens do projeto.

## Funcionalidades

- Navegação entre as seções.
- Apresentação do perfil profissional.
- Exibição de formação e habilidades.
- Área destinada aos projetos.
- Seção de contato.
- Layout responsivo.

## Execução local

Para visualizar o projeto, execute:

python -m http.server 8000

Depois, acesse no navegador:

http://127.0.0.1:8000
